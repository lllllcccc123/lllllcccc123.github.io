机载视觉驱动的人形动态搬运

通过 Motion Matching 拼接重定向动作，构建“行走—抓取—抱箱行走—放置”全流程技能；将 PPO 全身跟踪教师通过 BCPPO 蒸馏为指令驱动的学生。轻量 Depth CNN 回归 torso 系物体位姿，结合深度噪声对齐与域随机化，实现机载视觉驱动的多尺寸箱体搬运。

Motion Matching · PPO / BCPPO · Depth CNN · Domain Randomization · ROS

DiRT：条件扩散驱动的分层多技能移动操作

面向 X2 人形机器人，以 DiT + DDIM 条件扩散生成器规划未来 8×44D 末端—接触命令，通过 PPO / BCPPO 训练共享全身 Tracker，统一覆盖搬运、推箱与踢球等任务。高层 5 Hz 重规划、低层 50 Hz 控制，结合深度 CNN 与 RGB AprilTag 进行感知适配。

随机化条件下三类任务的仿真成功率均达 88%+；远端工作站实测扩散规划延迟约 67 ms。

DiT / DDIM · PPO / BCPPO · PyTorch · Isaac Lab · MuJoCo · RGB-D

AMP 风格约束下的人形走跑策略与视觉巡线

基于 AMP-PPO 分别训练后退、行走、慢跑与快跑教师，利用人类运动先验约束步态风格；通过速度条件门控与 MoE + DAgger 蒸馏为统一策略并在 MuJoCo 中验证。后续参与机器人运动会负责视觉巡线模块，前置 RGB 拟合跑道线生成走廊表示，驱动速度指令预测与运动控制闭环。

统一 4 类技能专家，策略以 50 Hz 控制；训练指令覆盖 −1 至 4.5 m/s。视频素材展示走跑仿真。

AMP-PPO · MoE / DAgger · RSL-RL · Isaac Lab · MuJoCo · TorchScript

分层异构多智能体空战博弈策略生成

使用 C++ / Pybind11 构建多进程向量化空战环境，上层 HAPPO 结合多阶段课程学习调度战术意图，下层 PPO 输出连续飞行控制。通过动作掩码与势函数奖励实现平滑执行，并将高层神经策略蒸馏为可解释决策树。

相比行为树基线，胜率提升 35%；获胜对局中高价值飞机生存率达 95%。前期工作已投稿 IEEE CEC。

HAPPO / PPO · C++ / Pybind11 · Curriculum Learning · Decision Tree Distillation
